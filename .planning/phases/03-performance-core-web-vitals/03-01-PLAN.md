<threat_model>
This plan is a build-graph and routing refactor. It does not touch consent, storage, network, or DOM-injection surfaces. ASVS L1 review:

- **Bundle integrity / chunk origin:** lazy chunks are produced by the same Rollup build and served from the same Cloudflare static-assets origin as the entry bundle (`wrangler.jsonc` `assets.directory`). No CDN switch, no cross-origin script load, no `import()` of a runtime-constructed URL. Mitigation: lazy imports use literal string paths only (`import('./pages/legal/AboutPage.jsx')`); the planner forbids dynamic concatenation.
- **No new outbound network calls:** the route split adds chunk fetches against the same origin as `index.html`, which is already in the Cloudflare same-origin allowlist. No new external host is contacted. AdSense (`pagead2.googlesyndication.com`) and Google Fonts remain the only third-party hosts, both gated by existing mechanisms.
- **No new dependency surface:** `package.json` is unchanged; `manualChunks` is a built-in Rollup option already shipped inside Vite 6. No `rollup-plugin-visualizer`, no analyzer dep, no polyfill dep.
- **CSP unaffected:** the app currently emits no custom `Content-Security-Policy` header; Cloudflare's default behaviour is unchanged. Lazy chunks load via `<script type="module" src="...">` tags injected by the runtime — the same mechanism already used for the entry bundle, so any future CSP added in a later phase would treat them identically.
- **No eval / no dynamic-script-injection beyond `useAdSenseLoader`:** the only `<script>` injection in the codebase remains the AdSense loader, which this plan does not touch. `React.lazy` uses standard ESM dynamic `import()`; it does not call `eval` or build a `<script>` element manually.
- **AdSense reviewer regression risk:** the visible home, pair, and exchange-rates-today surfaces stay eager — no flash-of-skeleton on the reviewer's primary path. Mitigation: `HomePage`, `CurrencyPairPage`, `ExchangeRatesTodayPage` are explicitly excluded from the lazy set; only routes a reviewer reaches by clicking (`/guides`, `/about`, etc.) see the skeleton, and only for the chunk-fetch duration (target < 150 ms on slow 4G per CONTEXT.md).
- **Layout shift on Suspense fallback unmount:** a brief skeleton → real-content swap could in theory produce CLS. Mitigation: skeleton `min-height: 60vh` is large enough that the real content almost always fits within or overflows that box, keeping the swap downward-only; Phase 3 plan 03-02 measures CLS on all three test pages and tightens reservation values if needed.

Severity ceiling: none at `high`. Proceed.
</threat_model>
